만화 — Manhwa Library
=====================

โครงสร้างไฟล์
-------------
index.html        หน้าหลัก
style.css         สไตล์ทั้งหมด (สีชมพูอ่อน + ขาว)
script.js         ตรรกะของแอป (IndexedDB, ฟอร์ม, modal)
manifest.json     PWA manifest
sw.js             Service Worker (ทำให้แอปเปิดออฟไลน์ได้ + ติดตั้งเป็นแอปได้)
icons/            ไอคอนตัวอักษรเกาหลี "만화"

วิธีใช้งาน
---------
**สำคัญ:** PWA ต้องเปิดผ่าน HTTP server (ไม่ใช่ double-click ไฟล์)

วิธีง่ายสุด — รันที่เครื่อง:
  cd manhwa-app
  python -m http.server 8080
แล้วเปิด http://localhost:8080

หรือ deploy ขึ้น Netlify/Vercel/GitHub Pages ฟรี → จะใช้บนมือถือได้
และกด "Add to Home Screen" เพื่อติดตั้งเป็นแอป

การเก็บข้อมูล
-------------
ข้อมูลถูกเก็บใน IndexedDB ของเบราว์เซอร์ (ไม่หายตอนล้าง cache แบบปกติ)
- ถ้าผู้ใช้เลือก "Clear all site data" หรือถอนการติดตั้งแอป ข้อมูลจะหาย
- แนะนำให้ใช้ "อื่นๆ → สำรองข้อมูล" สม่ำเสมอเพื่อ export เป็นไฟล์ JSON
- กู้คืนได้ผ่าน "อื่นๆ → กู้คืนข้อมูล"

ฟีเจอร์
-------
1. มังฮวา      — แสดง card ทั้งหมด กดปุ่ม "เปิด" จะเปิดในเบราว์เซอร์ระบบ (แท็บใหม่)
2. คอลเล็กชั่น  — จัดหมวดหมู่มังฮวาเป็นคอลเล็กชั่น (ต้องมีมังฮวาก่อน)
3. ค้นหา      — ค้นหาทุกหมวดในที่เดียว
4. นางเอก     — เก็บ card นางเอกในดวงใจ
5. อื่นๆ       — เพิ่มมังฮวา / จัดการข้อมูล / ประวัติการดู / Export-Import

มีเสียงคลิกเล็กๆ เวลากดปุ่ม (Web Audio synth — ไม่ต้องใช้ไฟล์เสียง)
