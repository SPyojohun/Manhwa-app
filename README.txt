만화 — Manhwa Library
=====================

โครงสร้างไฟล์
-------------
index.html        หน้าหลัก
style.css         สไตล์ทั้งหมด (สีชมพูอ่อน + ขาว)
script.js         ตรรกะของแอป (IndexedDB, ฟอร์ม, modal)
manifest.json     PWA manifest
sw.js             Service Worker (ทำให้แอปเปิดออฟไลน์ได้ + ติดตั้งเป็นแอปได้)
icons/            ไอคอนตัวอักษรเกาหลี "만화"

วิธีใช้งาน
---------
**สำคัญ:** PWA ต้องเปิดผ่าน HTTP server (ไม่ใช่ double-click ไฟล์)

วิธีง่ายสุด — รันที่เครื่อง:
  cd manhwa-app
  python -m http.server 8080
แล้วเปิด http://localhost:8080

หรือ deploy ขึ้น Netlify/Vercel/GitHub Pages ฟรี → จะใช้บนมือถือได้
และกด "Add to Home Screen" เพื่อติดตั้งเป็นแอป

การเก็บข้อมูล
-------------
ข้อมูลถูกเก็บใน IndexedDB ของเบราว์เซอร์ (ไม่หายตอนล้าง cache แบบปกติ)
- ถ้าผู้ใช้เลือก "Clear all site data" หรือถอนการติดตั้งแอป ข้อมูลจะหาย
- แนะนำให้ใช้ "อื่นๆ → สำรองข้อมูล" สม่ำเสมอเพื่อ export เป็นไฟล์ JSON
- กู้คืนได้ผ่าน "อื่นๆ → กู้คืนข้อมูล"

ฟีเจอร์
-------
1. มังฮวา      — แสดง card ทั้งหมด กดปุ่ม "เปิด" จะเปิดในเบราว์เซอร์ระบบ (แท็บใหม่)
2. คอลเล็กชั่น  — จัดหมวดหมู่มังฮวาเป็นคอลเล็กชั่น (ต้องมีมังฮวาก่อน)
3. ค้นหา      — ค้นหาทุกหมวดในที่เดียว
4. นางเอก     — เก็บ card นางเอกในดวงใจ
5. อื่นๆ       — เพิ่มมังฮวา / จัดการข้อมูล / ประวัติการดู / Export-Import

มีเสียงคลิกเล็กๆ เวลากดปุ่ม (Web Audio synth — ไม่ต้องใช้ไฟล์เสียง)

ระบบแชร์ (Share)
-----------------
แชร์:
  1. หน้า "มังฮวา" กดปุ่ม "เลือก" → แตะการ์ดเพื่อเลือก (เลือกเรื่องเดียวหรือหลายเรื่องก็ได้)
  2. กด "แชร์" → ได้ลิงก์ → คัดลอก หรือแชร์ผ่านแอปในเครื่อง
  3. เปิด/ปิด "แนบรูปปก" ได้ (ปิดแล้วลิงก์จะสั้นลงมาก)

รับ:
  - เปิดลิงก์ตรงๆ → แสดงหน้าตัวอย่าง ติ๊กเลือกเรื่องที่จะเก็บ → "ยอมรับ" หรือ "ปฏิเสธ"
  - หรือ อื่นๆ → "รับจาก URL (Receive from URL)" → วางลิงก์ → ดูตัวอย่าง
  - เรื่องที่มี URL ซ้ำกับในคลังจะติดป้าย "มีอยู่แล้ว" และไม่ถูกติ๊กให้อัตโนมัติ

หลักการทำงาน (ไม่มีเซิร์ฟเวอร์)
  ข้อมูลที่แชร์ถูกบีบอัดแล้วใส่ไว้ในลิงก์เอง (ส่วนหลัง #share=) จึงไม่มีอะไรถูกอัปโหลด
  และไม่มีวันหมดอายุ แต่ข้อจำกัดคือ:
  - ผู้รับต้องเปิดลิงก์ของแอปที่ deploy แล้ว (localhost ใช้แชร์ให้คนอื่นไม่ได้)
  - รูปปกจะถูกย่อเหลือ ~90px เพื่อให้ลิงก์ไม่ยาวเกินไป
  - ถ้าเลือกหลายเรื่องมากๆ ลิงก์จะยาว บางแอปแชทอาจตัดลิงก์ — ให้ปิดรูปปกหรือแชร์ทีละชุด
  - รับได้สูงสุด 100 เรื่องต่อหนึ่งลิงก์ และรับเฉพาะลิงก์ http/https เท่านั้น

อัปเดตแอป: sw.js ถูกเปลี่ยนเป็น manhwa-v2 เพื่อให้เครื่องที่ติดตั้งไว้แล้วได้โค้ดใหม่

การอัปเดต PWA บน GitHub Pages
-----------------------------
  - sw.js ใช้แบบ network-first: ออนไลน์จะดึงไฟล์ใหม่เสมอ ออฟไลน์ค่อยใช้ cache
    (ไม่ต้องแก้เลขเวอร์ชัน cache ทุกครั้งที่แก้โค้ดอีกต่อไป)
  - เมื่อตรวจพบเวอร์ชันใหม่ แอปจะรีโหลดตัวเองหนึ่งครั้ง
  - ถ้ายังเห็นของเก่า: อื่นๆ → "ตรวจสอบอัปเดต / รีเฟรชแอป" (ล้างเฉพาะ cache ของแอป ข้อมูลในคลังไม่หาย)
  - ไฟล์ index.html ต้องอยู่ที่ root ของ repo (ไม่ใช่ในโฟลเดอร์ย่อย)

รองรับทุกขนาดหน้าจอ
-------------------
  ทดสอบแล้วที่ 280 / 320 / 360 / 375 / 390 / 412 / 430 / 600 / 768 / 1024 / 1440 px และมือถือแนวนอน (740x360)
  - แถบเลือก (เลือก/ลบ/แชร์) ย่อให้พอดีบนจอเล็ก
  - ปุ่ม ยอมรับ/ปฏิเสธ/คัดลอก ลอยค้างด้านล่างของหน้าต่างเสมอ ไม่ต้องเลื่อนหา
  - ความสูงของหน้าต่างคำนวณตามพื้นที่จริงของเบราว์เซอร์มือถือ (dvh)
  - ไม่พึ่ง CSS :has() เพื่อรองรับ Safari/WebView รุ่นเก่า

ปักหมุด (Pinned / Favourites)
-----------------------------
  - แตะไอคอนหมุดที่มุมขวาบนของการ์ดมังฮวา (หน้ามังฮวา, ค้นหา, และในคอลเล็กชั่น) เพื่อปักหมุด/เลิกปักหมุด
  - ส่วน "ปักหมุด" อยู่ใต้ "ลิสต์วันนี้" แยกจากกัน เลื่อนซ้าย-ขวาได้ ไม่จำกัดจำนวน
    เรียงเรื่องที่เพิ่งปักล่าสุดไว้ก่อน แตะการ์ดเพื่อเปิดลิงก์ แตะหมุดเพื่อเลิกปักหมุด
  - ยังไม่มีเรื่องที่ปักหมุด: แสดงคำแนะนำสั้นๆ (ถ้าคลังว่างจะซ่อนส่วนนี้)
  - เก็บไว้ในข้อมูลของแต่ละเรื่อง (pinned) จึงถูกรวมในไฟล์ backup/restore
  - ไม่ถูกส่งไปกับลิงก์แชร์ (ผู้รับจะไม่ได้รับหมุดของคุณ)
  - ซ่อนชั่วคราวในโหมด "เลือก"
